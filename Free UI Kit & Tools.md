Heroicons → Alternative to Lucide (also excellent).

My Personal Advice for You:
Use Tailwind CSS + Lucide Icons + Swiper.js
Avoid Bootstrap (too heavy and generic for this elegant design)
Use pure CSS + Tailwind for everything possible
Keep Alpine.js only if you need reactive components (otherwise vanilla JS is enough)
